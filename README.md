---

# Sobre o projeto

O **FitSync** é uma plataforma focada no gerenciamento de:

- Academias
- Personais trainers
- Alunos
- Treinos
- Exercícios
- Acompanhamento de desempenho

O objetivo do projeto é fornecer uma solução moderna para gestão fitness, com suporte para aplicações web e mobile.
